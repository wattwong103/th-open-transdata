About this directory

TODM gathers free tools and open data sources for transportation in one place, so they are easier to find. Some sources require registration or charge for fuller access; the tags on each source say which.

The list started from a transport-infrastructure point of view. Sources from related fields, such as land use, environment and energy, are welcome.
